# Documentation retention / 文档保留

This public showcase is a documentation surface, not a source, evidence, or asset archive.

本公开展示仓库用于展示文档，不是源码、原始证据或素材归档库。

## Keep public history legible / 保持公开历史可追溯

- Keep dated reports at stable paths. Add a new dated record when status changes; do not rewrite an older result to make a later run appear continuous.
- Keep public summaries linked to the detailed report and state whether evidence is local verification, GitHub CI, live acceptance, or a product release.
- Preserve language parity between the English and Chinese entry points and keep relative links inside this showcase.
- Do not publish user screenshots, original reference images, source SVGs, private source code, ignored `.fdr` artifacts, or local receipts in this showcase.

- 带日期的报告保留在稳定路径。状态变化时新增日期记录，不改写旧结果来制造运行连续的印象。
- 公开摘要应链接到详细报告，并说明证据属于本地验证、GitHub CI、live 验收还是产品发布。
- 英文与中文入口保持信息对应；本展示仓库内的相对链接应可解析。
- 不在此处发布用户截图、原始参考图、源码 SVG、私有源码、被忽略的 `.fdr` artifact 或本地 receipt。
